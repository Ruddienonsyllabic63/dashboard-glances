1. IP do Servidor

Configure o IP público deste servidor para exibir nas instruções de firewall abaixo.

2. Instalar Glances no Cliente

Instale o Glances com suporte a API web (necessário para o dashboard).

Docker (Recomendado - mais simples)

# Instalar Docker (se não tiver) sudo apt install -y docker.io sudo systemctl start docker sudo usermod -aG docker $USER # Criar container Glances docker run -d \ --name glances \ -p 61208:61208 \ -v /var/run/docker.sock:/var/run/docker.sock:ro \ --pid host \ --privileged \ --restart unless-stopped \ nicolargo/glances:latest-full \ glances -w -B 0.0.0.0 # Verificar docker ps | grep glances curl -s http://localhost:61208/api/4/version

Ubuntu 24.04+ (virtualenv)

# Instalar dependências sudo apt update sudo apt install -y python3-venv python3-pip # Criar ambiente virtual sudo mkdir -p /opt/glances sudo python3 -m venv /opt/glances/venv sudo /opt/glances/venv/bin/pip install --upgrade pip sudo /opt/glances/venv/bin/pip install "glances[web]" # Verificar instalação sudo /opt/glances/venv/bin/glances --version # Criar serviço systemd sudo tee /etc/systemd/system/glances-web.service > /dev/null << 'EOF' [Unit] Description=Glances Web Interface After=network.target [Service] Type=simple User=root WorkingDirectory=/opt/glances ExecStart=/opt/glances/venv/bin/glances -w -B 0.0.0.0 -p 61208 Restart=always RestartSec=5 [Install] WantedBy=multi-user.target EOF sudo systemctl daemon-reload sudo systemctl enable glances-web sudo systemctl start glances-web # Verificar status sudo systemctl status glances-web curl -s http://localhost:61208/api/4/version

Windows (via Winget)

# Abrir PowerShell como ADMINISTRADOR # Passo 1: Instalar Python via Winget winget install Python.Python.3.12 # Fechar e reabrir PowerShell para atualizar PATH # Passo 2: Instalar Glances pip install "glances[web]" # Verificar instalação glances --version # Passo 3: Criar serviço Windows (opcional) pip install pywin32 sc.exe create Glances binPath= "C:\Users\SEU_USUARIO\AppData\Local\Programs\Python\Python312\python.exe -m glances -w -B 0.0.0.0 -p 61208" start= auto sc.exe description Glances "Glances System Monitor Web Interface" net start Glances # Verificar se está rodando curl http://localhost:61208/api/4/version # Passo 4: Configurar firewall (liberar porta 61208) # Opção A: Liberar apenas para o IP do servidor (recomendado) netsh advfirewall firewall add rule name="Glances Web" protocol=TCP dir=in localport=61208 remoteip="{{ config.get('server_ip', 'IP_DO_SERVIDOR') }}" action=allow # Opção B: Liberar para qualquer IP (menos seguro) # netsh advfirewall firewall add rule name="Glances Web" protocol=TCP dir=in localport=61208 action=allow

3. Configurar Firewall

Libere a porta 61208 no firewall do cliente para que o servidor possa acessar.

UFW (Ubuntu/Debian)

# Liberar apenas para o IP do servidor sudo ufw allow from {{ config.get('server_ip', 'IP_DO_SERVIDOR') }} to any port 61208 # Ou liberar para qualquer IP (menos seguro) sudo ufw allow 61208 sudo ufw reload

firewalld (CentOS/RHEL)

sudo firewall-cmd --permanent --add-rich-rule=' rule family="ipv4" source address="{{ config.get('server_ip', 'IP_DO_SERVIDOR') }}" port protocol="tcp" port="61208" accept' sudo firewall-cmd --reload

iptables

sudo iptables -A INPUT -p tcp -s {{ config.get('server_ip', 'IP_DO_SERVIDOR') }} --dport 61208 -j ACCEPT sudo iptables-save | sudo tee /etc/iptables/rules.v4

4. Testar Conexão

Verifique se o Glances está respondendo no cliente.

# Testar a API do Glances curl -s http://IP_DO_CLIENTE:61208/api/4/version # Deve retornar algo como: "4.5.6" # Verificar dados do sistema curl -s http://IP_DO_CLIENTE:61208/api/4/system

Adicionar no Dashboard

Vá em Configurações → Máquinas e adicione:

  • Nome: Nome amigável da máquina
  • Host: IP ou hostname do cliente
  • Porta: 61208 (padrão)
