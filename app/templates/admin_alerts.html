📧 Configuração de E-mail (SMTP)

Configure o servidor SMTP para envio de alertas e recuperação de senha.

Gmail: Use uma Senha de App (não sua senha normal).
Outlook: Host smtp.office365.com, porta 587.
SMTP local: Use localhost e porta 25.

🤖 Configuração do Telegram Bot

Receba alertas em tempo real via Telegram.

Como criar o Bot:

  1. Abra o Telegram e procure por @BotFather
  2. Envie /newbot
  3. Dê um nome para o bot (ex: Glances Alert Bot)
  4. Dê um username (ex: meu_glances_bot)
  5. Copie o token fornecido pelo BotFather
  6. Para obter seu chat_id, envie qualquer mensagem para o bot e acesse:
    https://api.telegram.org/bot<SEU_TOKEN>/getUpdates
    Procure por "chat":{"id": no resultado
